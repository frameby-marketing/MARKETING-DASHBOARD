## Google Sheets 구성 방법

### 1. 시트 생성

Google Sheets에서 새 스프레드시트를 만들고,  
시트 탭 이름을 **`매출데이터`** 로 변경합니다.

### 2. 헤더 및 데이터 입력

| A열 | B열 | C열 |
|-----|-----|-----|
| 월 | 자사몰+네이버 일평균 | 메모 |
| 26-05 | 400 | 프로모션 없음 |
| 26-06 | 440 | |
| 26-07 | 426 | 여름 시즌 |
| 26-08 | 426 | |
| 26-09 | 440 | |
| 26-10 | 426 | |
| 26-11 | 440 | |
| 26-12 | 426 | 연말 프로모션 |

- **A열**: `26-05` 형식으로 입력 (26년 5월)
- **B열**: 숫자만 입력 (단위: 만원), 미확정 월은 비워두면 됩니다
- **C열**: 선택 사항, 대시보드 툴팁에 표시됨

### 3. 공유 설정 (필수)

```
공유 버튼 → 링크 복사 → 
"링크가 있는 모든 사용자" → "뷰어" 선택
```

> ⚠️ 이 설정을 하지 않으면 대시보드에서 데이터를 읽을 수 없습니다.

### 4. 스프레드시트 ID 확인

URL에서 복사:
```
https://docs.google.com/spreadsheets/d/[여기가 ID]/edit#gid=0
```

## 초기 설정 순서 (대시보드 접속 후)

1. **설정 탭** 클릭
2. 스프레드시트 ID 입력
3. 시트 이름 확인 (`매출데이터`)
4. 범위 확인 (`A1:C13` — 헤더 포함 9행)
5. **설정 저장 및 연결** 클릭
6. 좌측 하단 싱크 상태가 초록색 ● 으로 바뀌면 연동 완료

## 계산 기준 요약

| 구분 | 매출 산정 방식 |
|------|--------------|
| 1~4월 | 확정 실적 고정값 |
| 5월 | 시트 입력 일평균 ÷ 0.68 × 31일 |
| 6~12월 | 1~4월 평균 광고비(4,850만원) ÷ 0.25 = **19,400만원** 고정 |

- 자사몰+네이버 비중: 68% (설정에서 변경 가능)
- 광고비/매출 비중: 25% (설정에서 변경 가능)
- 기초잔액: 26년 1월 1일 = 0원
- 자동 새로고침: 5분 간격

## 커스터마이징

`config.js`에서 비용 계획 수정:

```js
COSTS: {
  fixed: [7800, 6700, ...],  // 월별 고정비
  order: [5000, 10900, ...], // 월별 발주비
  ad:    [6800, 4300, ...],  // 5월까지만; 6~12월은 자동 계산
  other: [3800, 0, ...],     // 월별 기타변동비
}
```
